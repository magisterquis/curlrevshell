Usage
-----
```
Usage: wgetrevshell [options]

Wget to curlrevshell adapter

Options:
  -adapter-socket path
    	Unix socket path for adapters
  -debug
    	Print debugging messages
  -listen-address address
    	Listen address (default "0.0.0.0:5555")
  -prefix prefix
    	HTTP URL path prefix (default "/wgetrevshell")
  -tls-certificate-cache file
    	Optional file in which to cache generated TLS certificate (default "/home/you/.cache/sstls/cert.txtar")
```
