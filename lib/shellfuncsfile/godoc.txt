package shellfuncsfile // import "github.com/magisterquis/curlrevshell/lib/shellfuncsfile"

Package shellfuncsfile takes a file or directory and turns it into shell
functions.

The general idea is to make a Converter, and every time a shell functions file
is needed, call Converter.From to get a nice slice of bytes. If a directory is
passed, files in the directory are converted to shell functions which is handy
for scripts written in other languages, e.g. Perl.

Note that all of this is inherently racy. Don't use this in situations where
it's reasonably likely that files will change during calls to anything in this
package.

CONSTANTS

const (
	// DocPrefix indicates a line is meant to be used for documenting a
	// function.
	DocPrefix = "# TABDOC:"
	// NoDocDirective, if found anywhere in the input to GenFuncList,
	// causes GenFuncList to return an empty slice.  This makes it a bi
	// easier to emit code for non-Unix shells without changing how this
	// library is called.
	NoDocDirective = DocPrefix + "NOTABLIST"
	// ListFuncName is the name of the function generated by GenFuncList.
	ListFuncName = "tab_list"
	// ListFuncDesc is the description for sff_list
	ListFuncDesc = "This function list"
)

FUNCTIONS

func FromPerl(name string, r io.Reader) ([]byte, error)
    FromPerl converts the Perl script read from r into a shell function.
    If there is no perl, the function body is empty.

func FromShell(_ string, r io.Reader) ([]byte, error)
    FromShell returns the bytes read from r, under the assumption that r already
    has shell functions.

func GenFuncList(s string) ([]byte, error)
    GenFuncList generates a function which prints a list of functions from the
    lines starting with DocPrefix in s.

    It makes a two-column table using the first word after DocPrefix for the
    first column and the rest of the line for the second column. The lines in
    the table will be sorted in lexicographical order.


TYPES

type Converter struct {
	// FS is the converter's underlying source of files.  If unset, the
	// filesystem (e.g. [os.Open]) will be used.
	// FS must not be modified during a call to Converter.From.
	FS interface {
		fs.FS
	}

	// AddListFunction adds an additional shell function to From's output
	// which lists other functions.  See the [GenFuncList] for more info.
	// AddListFunction must not be modified during a call to
	// Converter.From.
	AddListFunction bool

	// Has unexported fields.
}
    A Converter converts files or directories into shell functions. A zero
    converter is valid, but has no filters.

func NewDefaultConverter() *Converter
    NewDefaultConverter returns a new converter with the default set of filters,
    which are the package-level From* functions. The default filters and
    corresponding file glob patterns are:
      - FromPerl: *.pl
      - FromShell: *.ctrl-i *.sh *.subr

func (c *Converter) From(sources ...string) ([]byte, error)
    From takes as its source either a file or a directory and returns a slice of
    bytes containing shell functions.

    If the source is a file, From returns its contents, possibly converted
    should any Filter's patterns match.

    If the source is a directory, From filters and concatenates all of the
    regular files in the directory, sorted lexicographically by name, whose
    names do not start with a period, adding newlines as needed.

    Filter patterns will be tried in lexicographical order.

func (c *Converter) SetFilter(ext string, filter Filter)
    SetFilter sets the filter for a given file name glob pattern, which will
    be matched with filepath.Match. Set a nil filter to disable handling that
    pattern.

type Filter func(filename string, r io.Reader) ([]byte, error)
    A Filter converts read bytes into one or more shell functions, as
    appropriate.

type InvalidTypeError struct {
	FI fs.FileInfo
}
    InvalidTypeError is returned from Converter.From when the source is neither
    a regular file nor directory.

func (err InvalidTypeError) Error() string
    Error implements the error interface.
