package tlog // import "github.com/magisterquis/curlrevshell/lib/tlog"

Package tlog - Testing-friendly logger

CONSTANTS

const BufLen = 10240
    BufLen is the size of Buffer's internal buffers.


VARIABLES

var ErrBufferClosed = errors.New("buffer closed")
    ErrBufferClosed is returned by Buffer.Write if the buffer was closed before
    saving a message.

var ErrBufferEmpty = errors.New("buffer empty")
    ErrBufferEmpty indicates we were non-blocking reading from the buffer and it
    ran out of messages.

var ErrBufferFull = errors.New("buffer full")
    ErrBufferFull is returned by Buffer.Write when its internal buffer is full.

var M = NewMsg()
    M is a convenient way to start a new Msg.


FUNCTIONS

func S(s string) string
    S appends a hyphen and a random base36 uint64 number to s.


TYPES

type Buffer struct {
	// Has unexported fields.
}
    Buffer holds log messages received from the slog.Logger returned by New.
    The With* methods return a copy of Buffer with options set but with the same
    underlying storage.

func NewBuffer() (*Buffer, *slog.Logger)
    NewBuffer returns a new Buffer and logger to write to the buffer. Logs
    will be written at level DEBUG. The buffer will have space for BufLen log
    entries.

func (l *Buffer) Clone() *Buffer
    Clone returns a copy of l which shares l's underlying buffers and closed
    atomic Bool.

func (l *Buffer) Close() error
    Close marks l as closed and returns nil. It may be called more than once.
    Further writes will return an error but will be noted for a later call to
    l.TestEmptyAfterClose.

func (l *Buffer) CloseExpectEmpty(ctx context.Context, t *testing.T) bool
    CloseExpectEmpty is a convenience method which first closes l and then makes
    sure there are no buffered logs.

func (l *Buffer) Expect(ctx context.Context, t *testing.T, msgs ...Msg) bool
    Expect checks that the next log messages are equivalent to msgs (which
    may be no messages) and marks t as failed and prints a messages if not.
    Unless WithExpectUnordered was used, messages are expected to be in the
    order passed to Expect.

func (l *Buffer) IsClosed() bool
    IsClosed indicates if l.Close has been called.

func (l *Buffer) NextMessage(ctx context.Context) (Msg, error)
    NextMessage returns the next buffered message, according to l's
    configuration.

func (l *Buffer) Strings() []string
    Strings unbuffers and returns the strings in l.

func (l *Buffer) TestEmptyAfterClose(t *testing.T) bool
    TestEmptyAfterClose notes test failures if messages were written to
    l after l.Close was called. Each message written after close before
    TestEmptyAfterClose are called will be one test failure, messages written
    during the call to TestEmptyAfterClose may be noted as a test failure,
    and messages written after TestEmptyAfterClose will not be noted as a test
    failure unless another call to TestEmptyAfterClose is made. if l.Close has
    not been closed, TestEmptyAfterClose closes l.

func (l *Buffer) WithExpectEmpty() *Buffer
    WithExpectEmpty returns a copy of l configured such that Expect also notes
    a test failure if there were more buffered messages than passed to expect.
    Leftover buffered messages will be unbuffered and logged as test failures.

func (l *Buffer) WithExpectUnordered() *Buffer
    WithExpectUnordered returns a copy of l configured such that Expect does not
    expect logged messages to be in order.

func (l *Buffer) WithNoWait() *Buffer
    WithNoWait returns a copy of l configured such that expect does not block
    waiting for as many log messages as it was passed.

func (l *Buffer) Write(b []byte) (int, error)
    Write adds the lines b to l's internal buffer with no newlines. It returns
    0, ErrBufferFull if l's internal buffer is full.

type Group = map[string]any
    Group is analogous to the group created by slog.Logger.WithGroup.

type Msg struct {
	// Has unexported fields.
}
    Msg is a log message in Go terms. It can either be built up with NewMsg and
    its methods or be unmarshalled from a JSON object. Msgs methods which return
    a Msg return a deep copy of the Msg.

func NewMsg() Msg
    NewMsg is a convenience function which returns a new Msg, ready for use.
    M may be more convenient for many use-cases.

func NewMsgFromJSON(s string) (Msg, error)
    NewMsgFromJSON decodes the JSON object in s to a Msg. Calls to With
    and WithGroup add to the outermost group. This is meant to unmarshal
    JSON generated by slog.JSONHandler. For native Msg serialization, see
    Msg.MarshalJSON and Msg.UnmarshalJSON.

func (m Msg) Clone() (Msg, error)
    Clone returns a deep copy of Msg. Under the hood, it marshals to and from
    JSON.

func (m Msg) Debug(msg string) Msg
    Debug is a convenience method to Log at level slog.Debug.

func (m Msg) Equal(n Msg) bool
    Equal indicates whether m and n encode to the same JSON via Msg.String.
    If either m or n are unable to be encoded to json, Equal panics.

func (m Msg) Error(msg string) Msg
    Error is a convenience method to Log at level slog.Error.

func (m Msg) Info(msg string) Msg
    Info is a convenience method to Log at level slog.Info.

func (m Msg) IsZero() bool
    IsZero indicates if m is Msg{}.

func (m Msg) Log(level, msg string) Msg
    Log returns a clone of m with a "level" (slog.LevelKey) attribute in the
    outermost group set to level and a "msg" (slog.MessageKey) attribute in the
    outermost group set to msg. m is not modified. Log panics on error.

func (m Msg) MarshalJSON() ([]byte, error)
    MarshalJSON returns the JSON form of m. Note that this is not the same as
    the what slog.JSONHandler produces.

func (m Msg) MustClone() Msg
    MustClone is like Clone, but panics on error.

func (m Msg) String() string
    String returns the JSON form of m. It panics if m cannot be encoded to JSON.
    See Msg.ToJSON for more details.

func (m Msg) ToJSON() (string, error)
    ToJSON returns the JSON form of the log message in m, eliding empty groups.
    This is the inverse of NewMsgFromJSON and should return the same JSON object
    produced by slog.JSONHandler, albeit possibly with a different key ordering.

func (m *Msg) UnmarshalJSON(b []byte) error
    UnmarshalJSON updates m with the contents of the JSON object in b. This
    should nearly always be called as NewMsg().UnmarshalJSON(...).

func (m Msg) Warn(msg string) Msg
    Warn is a convenience method to Log at level slog.Warn.

func (m Msg) With(key string, value any) Msg
    With returns a clone of m with a new value added, similar to
    slog.Logger.With. If the key already exists, its value is changed in
    the clone. The value must be able to be marshalled to JSON, otherwise
    With panics. Error values are stored as strings, for compatibility with
    slog.JSONHandler.Handle.

func (m Msg) WithGroup(name string) Msg
    WithGroup returns a clone of m which adds keys and values with With to
    a new group with the given name. If the name already exists as a key,
    it is replaced.
